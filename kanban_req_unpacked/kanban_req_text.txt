1. プロジェクト概要
本ドキュメントは、Next.js と Supabase を用いて構築する「看板ボード風タスク管理アプリケーション」の要件を定義するものです。段階的開発（アジャイル開発）の手法により、基本機能から始めて最終的にデータベース連携した本格的なWebアプリケーションを完成させることを目指します。

4. 機能要件
本アプリケーションは以下の6段階で段階的に機能を追加する形で開発します。

4.1 基本タスク管理機能（CRUD）
タスク追加機能
テキスト入力欄にタスク名を入力できる
「追加」ボタンをクリックするとタスクをリストに追加できる
追加後、入力欄はクリアされる

タスク表示機能
追加されたタスクをリスト形式で表示する
シンプルで見やすいデザインで表示する

タスク完了機能
各タスクにチェックボックスを配置する
チェックボックスをクリックすると完了状態に切り替わる
完了状態のタスクはテキストに取り消し線を表示する
完了済みタスクと未完了タスクを視覚的に区別する
再度クリックすることで未完了状態に戻せる

タスク削除機能
各タスクに削除ボタン（× ボタン、またはゴミ箱アイコン）を配置する
削除ボタンをクリックすると即座にタスクを削除する
削除の確認ダイアログは不要（即削除）
削除後は他のタスクに影響を与えない

4.2 UIデザイン要件（カンバンボード）
「未完了」「完了済み」の2カラム構成で表示する
各カラムにヘッダー（「未完了」「完了済み」など）を表示する
タスクをカード形式（影・角丸・色分け）で表示する
モダンで美しいデザインに統一する
レスポンシブデザイン対応（スマートフォンでも閲覧可能）
新規追加タスクは「未完了」カラムに追加される
チェックで完了にすると「完了済み」カラムに移動する
ドラッグ&ドロップでタスクを移動できる

4.3 ユーザー認証機能
新規登録
名前・メールアドレスを入力して新規登録できる
登録成功後、そのユーザーで自動ログインされる

ログイン
登録済みユーザーをドロップダウンから選択してログインできる（初期データ：田中太郎、佐藤花子、山田次郎）
ログイン後、画面上部に「ようこそ、○○さん」と表示する
ログイン状態をローカルストレージで保持する
ページをリロードしてもログイン状態が維持される

ログアウト
ログアウトボタンを押すとログイン画面に戻る

マルチユーザー対応
ログイン中のユーザーのタスクのみ表示・管理する
ユーザーごとのタスクを正しく分離する



4.4 コメント機能
コメント表示
各タスクカードの下にコメント一覧を表示する
コメントには投稿者名と内容を表示する
コメントがない場合は「コメントはありません」と表示する

コメント追加
各タスクカードにコメント入力欄と追加ボタンを配置する
現在ログイン中のユーザーがコメント投稿者となる
コメント追加後は入力欄をクリアする

コメントデザイン
コメントは淡いグレー背景で区別する
カンバンボードの各カード内に見やすく配置する
タスクとコメントが視覚的に分かりやすい配置にする

4.5 データ永続化（Supabase連携）
タスク・ユーザー・コメントデータをSupabaseのデータベースに保存する
ページをリロードしてもデータが消えない
複数のブラウザタブで同一データを参照できる
別タブでの変更がリアルタイムに反映される
異なるデバイスからアクセスしても同じデータが表示される

6. 除外範囲

理由

本要件定義の対象外

学習用途のローカル開発のみ対象
メール認証（Confirm email）
学習目的のため無効化
パスワード暗号化・セキュアなセッション管理
学習用途のため簡易実装
CI/CDパイプラインの構築
本要件定義の対象外
テストコードの実装（単体・結合・E2Eテスト）
本要件定義の対象外
多言語対応（i18n）
本要件定義の対象外
タスクの優先度設定・期限管理
本要件定義の対象外
ファイル添付機能
本要件定義の対象外

7. 制約
7.1 環境制約
Node.js がインストールされた環境で動作させること
npm コマンドが利用可能であること
Supabase アカウントを保有し、プロジェクトが作成済みであること

7.2 セキュリティ制約
APIキー（NEXT_PUBLIC_SUPABASE_URL、NEXT_PUBLIC_SUPABASE_ANON_KEY）は .env.local ファイルで管理する
.env.local ファイルは Git にコミットしない
APIキーや接続情報を他者と共有しない
